# Do'kon logotiplari

Bu papkadagi `<do'kon-id>.webp` fayllari `npm run store-logos` buyrug'i bilan
bir marta yuklab olinadi (favicon xizmatlaridan, 128 px WebP ga o'girilib).

`index.json` — mavjud logotiplar ro'yxati. Ilova shu ro'yxatga qarab rasmni
lokal fayldan oladi; ro'yxatda bo'lmagan do'konlar uchun favicon xizmatidan
bir marta yuklanadi (keyin service worker keshidan) yoki rangli monogramma
ko'rinadi.

Logotiplar tegishli brendlarning tovar belgilari; ular faqat o'sha do'konni
ko'rsatish uchun ishlatiladi.
